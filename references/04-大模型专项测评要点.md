# 04 大模型专项测评要点（六域）

> 依据 T/ISEAA 006-2024《大模型系统安全测评要求》第 6~9 章（条款级对应见 `08-T-ISEAA006-2024标准映射.md`）、GB/T 45654-2025《生成式人工智能服务安全基本要求》、GB 45438-2025《内容标识方法》整理。专项测评 = 文档核查（制度/记录） + 技术测试（用例见 07-大模型专项测试用例库.md）。每个域附"达标产品/工具参考"，便于核查与整改选型（产品为常见形态参考，符合性判定以功能要求为准）。

## 域 1：语料安全（006: 6.1.1 数据收集、6.1.2 数据清洗、6.1.3 数据标注；5.11 个人信息）

| 测评点 | 核查/测试内容 | 判定要点 |
|---|---|---|
| 语料来源合规 | 语料来源清单（网站、购买、爬取、用户上传）、授权证明 | 来源可追溯；爬取有 robots 协议与版权评估 |
| 语料内容安全 | 语料中涉政、涉恐暴、色情、违法内容过滤记录 | 过滤规则+过滤后抽检记录 |
| 个人信息保护 | 语料含个人信息是否获授权、是否脱敏 | 授权记录/脱敏报告；敏感个人信息处理单独同意 |
| 知识产权 | 语料版权评估、侵权投诉处理机制 | 评估记录、投诉处理流程 |
| 质量与偏见 | 语料质量评估、偏见/歧视样本检测 | 质量评估报告 |

**达标产品/工具参考**：数据采集与治理平台（星环、DataCanvas、自研管道）、敏感信息识别（网易易盾、百度 AI 审核、自研 NER+正则引擎）、数据脱敏（美创、安华金和、闪捷信息）、语料质检（质检平台+人工抽检）。

## 域 2：训练安全（006: 6.2 h) 环境隔离、8.2 c) 训练攻击检测）

| 测评点 | 核查/测试内容 | 判定要点 |
|---|---|---|
| 训练环境隔离 | 训练集群与公网/生产隔离、数据不出域 | 网络策略、数据流图 |
| 训练过程审计 | 训练任务日志、数据加载日志、模型产出日志 | 日志留存与完整性 |
| 数据投毒防护 | 异常样本检测、数据血缘、质量门禁 | 检测机制与告警 |
| 训练资源管控 | 算力配额、异常任务告警 | 配额策略、告警记录 |
| 对齐与价值观 | 训练阶段安全对齐（RLHF/DPO）、安全评价指标 | 对齐方案、评测报告 |
| 断点与容错 | checkpoint 机制、断电恢复 | 配置与演练 |

**达标产品/工具参考**：GPU 算力服务器（浪潮、新华三、华为昇腾、寒武纪、海光）、液冷系统（英维克、曙光）、训练平台（KubeFlow、云厂商 MaaS、NVIDIA NeMo）、调度与配额（K8s 资源配额）、训练监控（Weights & Biases、MLflow）、数据血缘（OpenLineage、星环）。

## 域 3：模型安全（006: 6.2 模型保护、7.1 模型评估）

| 测评点 | 核查/测试内容 | 判定要点 |
|---|---|---|
| 模型文件完整性 | 权重哈希/签名校验、加载前验证 | 校验机制配置 |
| 模型版本管理 | 版本化、发布审批、回滚 | 版本记录+审批单 |
| 后门检测 | trigger 测试、供应链模型检测 | 检测报告（第三方或自研） |
| 鲁棒性 | 对抗样本测试（文本扰动、编码混淆） | 测试报告+改进记录 |
| 水印与溯源 | 模型水印、输出溯源 | 水印方案与验证 |
| 防窃取 | 防蒸馏、限流、许可证 | 防护配置 |

**达标产品/工具参考**：模型仓库（私有化 Hugging Face/ModelScope、MLflow Model Registry）、AI 安全评估平台（绿盟、启明星辰、奇安信、360、蚂蚁集团）、对抗样本工具（CleverHans、ART、TextAttack）、模型水印方案（中科睿鉴及厂商方案）、模型签名（配合 DevOps/安全网关）。

## 域 4：推理服务安全（006: 6.2 c)、6.3、8.2 d)、8.3）

| 测评点 | 核查/测试内容 | 判定要点 |
|---|---|---|
| 提示注入防护 | 直接/间接/多轮注入测试（用例见 07） | 拦截率、防护日志 |
| 越狱防护 | 角色扮演、编码绕过、虚构场景测试 | 拒绝率、防护规则更新 |
| 输入过滤 | 输入侧关键词/分类模型过滤 | 过滤规则与拦截日志 |
| 输出过滤 | 输出侧检测+人工抽审 | 审核流程、拦截率统计 |
| 内容标识 | 显式标识（文字/图形）+ 隐式标识（元数据/水印） | 抽测标识存在性与隐蔽性 |
| 幻觉治理 | 高危场景幻觉率测试、引用溯源 | 测试结果、拒答机制 |
| API 安全 | 鉴权、限流、越权、敏感信息 | 接口测试结果 |
| 会话安全 | 跨会话串话、上下文泄露 | 专项测试 |

**达标产品/工具参考**：大模型应用防火墙 MAF（启明星辰、绿盟 NSFOCUS AI、360、安恒、瑞数信息）、内容审核（网易易盾、百度 AI 审核、腾讯云天御、阿里云内容安全）、API 网关（APISIX、Kong、云厂商 API 网关）、推理引擎（vLLM、TGI、SGLang）+ 鉴权插件、向量数据库（Milvus、Weaviate、Elasticsearch）权限控制、Agent 安全组件（LangSmith、Guardrails）。

## 域 5：内容安全（006: 6.3 内容安全、8.6 安全事件处置）

| 测评点 | 核查/测试内容 | 判定要点 |
|---|---|---|
| 八大类风险过滤 | 涉政、涉恐暴、色情、虚假信息、歧视、违法、侵犯权益、其他有害 | 分场景测试通过率 |
| 投诉举报处理 | 投诉渠道、响应时限、处置闭环 | 台账与记录 |
| 未成年人保护 | 适龄提示、防沉迷、未成年人内容过滤 | 实现与测试 |
| 用户协议与告知 | 服务协议、隐私政策、风险提示 | 文档与展示 |
| 安全评估与备案 | 算法备案、安全评估报告 | 备案编号、评估结论 |

**达标产品/工具参考**：内容安全审核平台（网易易盾、百度 AI 审核、腾讯云天御、阿里云内容安全）、内容标识服务（中科睿鉴、平台自研标识组件）、舆情监测（清博、人民在线）、人工审核工作台（自建或审核外包平台）。

## 域 6：数据安全（006: 5.11、5.12、5.14、9.2）

| 测评点 | 核查/测试内容 | 判定要点 |
|---|---|---|
| 数据分级分类 | 训练/推理/用户数据分级清单 | 清单与标识 |
| 脱敏与加密 | 语料脱敏、存储加密、传输加密 | 配置核查+抽测 |
| 用户数据最小化 | 输入输出留存策略、不用于训练（或授权） | 隐私政策+删除接口测试 |
| 数据删除/遗忘 | 用户删除请求处理、模型遗忘机制 | 删除流程测试 |
| 知识库权限 | RAG 知识库分级访问、越权测试 | 权限矩阵+测试 |

**达标产品/工具参考**：数据脱敏系统（美创、安华金和、闪捷信息、亿赛通）、DLP（天融信、亿赛通、明朝万达）、数据库加密（安华金和、美创）、隐私计算（蚂蚁摩斯、华控清交、富数科技、洞见科技）、数据分类分级工具（美创、数安行、绿盟）。

## 测评执行顺序建议

1. 文档核查先行（语料来源、备案、制度）→ 2. 配置核查（隔离、鉴权、过滤）→ 3. 功能测试（标识、删除接口）→ 4. 对抗测试（注入/越狱/泄露，见 07）→ 5. 数据汇总判定。
