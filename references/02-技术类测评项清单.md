> 📎 测评项与 T/ISEAA 006-2024 的条款级对应关系见 `08-T-ISEAA006-2024标准映射.md`（006 条款号 x.y 为正式引用编号）。

> 编号沿用等保通用框架；「LLM-」前缀为大模型扩展/专项项（依据大模型扩展要求征求意见稿要点与 GB/T 45654-2025 整理，正式发布后核对）。每项给出：测评方法（I/C/T/A）、关键核查点、符合性判据。

## 二、安全通信网络

| 控制点 | 测评项要点 | 方法 | 关键核查点 |
|---|---|---|---|
| 网络架构 | 划分安全区域、带宽保证、通信线路冗余 | I+C+T | 网络拓扑图与实际一致；核心链路冗余 |
| 通信传输 | 加密传输（SSH/HTTPS/IPSec/VPN） | C+T | 抓包或配置核查：管理通道、数据传输是否加密 |
| 可信验证 | 通信设备可信验证（三级） | C | 可信根、验证配置 |

**大模型扩展（LLM-）**：
- LLM-NET-1 (006: 5.2) 训练/推理/管理网络隔离：训练集群内部高速网络（RDMA/IB）、推理网络、管理网络分段隔离，核查 VLAN/物理隔离配置。
- LLM-NET-2 (006: 5.2) 模型与数据跨网传输管控：模型文件、训练数据跨区域传输须加密且经审批，核查传输通道（堡垒机/加密通道）与审批记录。
- LLM-NET-3 (006: 5.2) 外部模型 API 调用通道安全：调用第三方大模型 API 使用 HTTPS/TLS，密钥不落盘明文，核查配置。

- LLM-BND-2 (006: 5.3) 训练数据出域控制：训练数据、模型参数对外传输须审批+审计，核查 DLP 或边界管控策略。
- LLM-BND-3 (006: 5.3) 推理接口滥用防护：API 限流、配额、异常调用检测（防爬取、防批量探测），核查网关限流配置与告警。

### 4.2 大模型扩展（LLM-，重点测评区）

**身份与权限（LLM-ACC）**：
- LLM-ACC-1 (006: 5.5 i)) 模型仓库/模型管理平台访问控制：模型文件上传、下载、发布权限最小化，核查模型仓库（如 ModelScope/HF 私有化实例）权限配置与操作审计。
- LLM-ACC-2 (006: 5.5 l)) 训练任务权限隔离：不同团队/项目训练任务资源与数据隔离（K8s namespace、配额），核查隔离配置。
- LLM-ACC-3 (006: 5.4 d)) 推理 API 鉴权：API Key/Token 认证、密钥轮换、密钥泄露检测，核查网关鉴权与密钥管理。
- LLM-ACC-4 (006: 5.4 e)) 管理面与业务面账号分离：模型管理、训练管理、推理服务管理账号分离。

**模型安全（LLM-MOD）**：
- LLM-MOD-1 (006: 6.2 e)) 模型文件完整性校验：模型权重文件哈希校验、签名验证，防篡改/防投毒，核查加载前校验机制。
- LLM-MOD-2 (006: 7.2、8.5) 模型版本管理：模型版本化、发布审批、回滚机制，核查版本记录与审批单。
- LLM-MOD-3 (006: 5.10 b)) 模型来源可信：自研/开源/第三方模型来源登记、许可证合规、已知漏洞核查，核查模型台账。
- LLM-MOD-4 (006: 6.2 b)、8.2 b)) 模型后门与投毒检测：训练后模型后门检测（trigger 测试）、供应链模型安全检测，核查检测报告（专项测试 A）。
- LLM-MOD-5 (006: 7.1 a)、6.2 d)) 模型鲁棒性：对抗样本/扰动测试结果，核查测试报告与改进记录（A）。
- LLM-MOD-6 (006: 6.2 i)、5.14 b)) 模型知识产权保护：模型水印、溯源机制，核查水印方案（A/C）。
- LLM-MOD-7 (006: 8.2 a)) 模型窃取防护：防蒸馏/防白盒窃取措施（限流、日志告警、许可证约束），核查防护配置（A/C）。

**推理服务安全（LLM-INF）**：
- LLM-INF-1 (006: 6.2 c)、8.2 a)) 提示注入防护：直接注入、间接注入（RAG/工具内容）、多轮注入防护，专项测试（A）。
- LLM-INF-2 (006: 6.2 c)) 越狱防护：对抗性越狱手段（角色扮演、编码绕过、虚构情境）防护有效性，专项测试（A）。
- LLM-INF-3 (006: 6.3 a)) 输入内容过滤：用户输入涉政/涉恐暴/色情/违法等过滤，核查过滤规则与拦截日志（A）。
- LLM-INF-4 (006: 6.3 c)) 输出内容过滤：生成内容安全检测（关键词+分类模型+人工审核），核查审核流程与拦截率（A/C）。
- LLM-INF-5 (006: 6.3 e)~h)) 生成内容标识：按 GB 45438-2025 添加显式/隐式标识，核查标识实现与抽测（A/C）。
- LLM-INF-6 (006: 7.1 b)、8.3 a)) 幻觉治理：关键场景（医疗、金融、政务）幻觉率测试与提示策略（引用溯源、拒答机制），专项测试（A）。
- LLM-INF-7 (006: 6.3、8.2) RAG 检索安全：知识库访问控制、检索内容权限过滤、检索注入防护，专项测试（A）。
- LLM-INF-8 (006: 5.5 j)k)、8.2) Agent 工具调用安全：工具调用权限最小化、工具输出校验（防间接注入）、敏感操作二次确认，专项测试（A）。
- LLM-INF-9 (006: 8.3) 上下文/会话安全：会话数据隔离、上下文窗口泄露防护（跨会话串话测试），专项测试（A）。

**训练过程安全（LLM-TRN）**：
- LLM-TRN-1 (006: 6.2 h)) 训练环境隔离：训练环境与生产/互联网隔离，数据不出域，核查网络策略。
- LLM-TRN-2 (006: 5.6 c)) 训练日志审计：训练任务、数据加载、模型产出全流程日志，核查日志完整性。
- LLM-TRN-3 (006: 8.3 b)) 训练资源滥用防护：算力资源配额、异常任务检测，核查配额策略与告警。

**数据安全（LLM-DAT）**：
- LLM-DAT-1 (006: 6.1.1、6.1.2) 训练语料安全：语料来源合法合规、版权与个人信息授权、敏感信息识别与过滤，核查语料来源清单与过滤记录（对应 GB/T 45654-2025 语料安全要求）。
- LLM-DAT-2 (006: 6.1.2 d)、5.11) 语料/数据脱敏：个人敏感信息、商业秘密脱敏处理，核查脱敏工具与效果抽测（A）。
- LLM-DAT-3 (006: 8.2 c)) 数据投毒防护：数据质量校验、异常样本检测、数据血缘，核查检测机制。
- LLM-DAT-4 (006: 5.11 d)、5.12、9.2) 用户数据保护：用户输入输出数据不用于训练（或经授权）、留存策略、删除机制（数据遗忘/擦除），核查隐私政策与删除接口测试（A）。
- LLM-DAT-5 (006: 5.5 i)) 知识库数据分级：RAG 知识库数据分级分类、高敏数据访问控制，核查分级清单与权限（A）。
