# 06 高风险判定指引（2025版 + 大模型高风险项）

> 依据《网络安全等级保护测评高风险判定指引（2025版）》与 T/ISEAA 006-2024 第 10 章判定逻辑整理。命中高风险项 → 整体测评结论"不符合"（对应等保"不满足"），必须整改并复测。006 第 10.3 条：存在导致高等级安全风险的问题即判定"不符合"；中低风险比例超过阈值亦判定"不符合"。

## 一、2025版高风险判定核心要点（通用）

| 类别 | 高风险情形（示例） | 说明 |
|---|---|---|
| 定级备案类 | 未定级备案、定级不准（故意降级） | 一票否决类 |
| 测评开展类 | 三级系统未按规定每年测评、二级每两年测评 | 一票否决类 |
| 物理与环境 | 机房无任何物理访问控制、无消防设施 | 严重缺失 |
| 网络架构类 | 系统直接暴露公网无边界防护；核心业务无冗余 | 边界失效 |
| 身份鉴别类 | 存在空口令/默认口令/弱口令普遍存在；管理账号无口令策略 | 严重弱鉴别 |
| 访问控制类 | 越权访问严重、特权账号共享无审计 | 权限失控 |
| 数据安全类 | 敏感数据明文存储且无访问控制；备份缺失且无恢复能力 | 数据失控 |
| 审计类 | 三级系统无任何审计或审计日志被篡改 | 审计失效 |
| 漏洞类 | 存在已公开高危漏洞未修复且可利用 | 高危漏洞 |
| 管理类 | 安全管理制度体系完全缺失、无安全负责人 | 管理空白 |

## 二、大模型系统特有高风险项（LLM-HR）

| 编号 | 高风险情形 | 风险描述 | 判定要点 |
|---|---|---|---|
| LLM-HR-1 | 模型可被越狱/提示注入突破且无内容过滤 | 可诱导生成违法有害内容（涉政、恐暴、色情、虚假信息）且无输出过滤，面向公众服务时危害放大 | 越狱测试成功率>阈值且无输出过滤；面向公众服务直接判高风险 |
| LLM-HR-2 | 训练语料含未脱敏敏感个人信息/涉密数据 | 训练数据泄露个人隐私、商业秘密、涉密信息，模型可能输出 | 语料抽测发现明文敏感信息且无脱敏措施 |
| LLM-HR-3 | 推理 API 无鉴权或可被任意调用 | 接口裸奔导致滥用、资源盗用、数据泄露 | 接口测试未认证可调用 |
| LLM-HR-4 | 提示注入可导致数据泄露（RAG/Agent） | 通过注入读取知识库内部文档、越权调用工具、获取敏感数据 | 注入测试成功读取受限数据 |
| LLM-HR-5 | 模型文件无完整性校验、来源不可信 | 供应链投毒、模型被篡改，后门风险 | 加载无校验、来源无登记 |
| LLM-HR-6 | 面向公众服务未完成算法备案/安全评估 | 违反《生成式人工智能服务管理暂行办法》 | 备案缺失 + 面向公众 |
| LLM-HR-7 | 生成内容无标识（面向公众服务） | 违反 GB 45438-2025 强制性要求 | 抽测无显式/隐式标识 |
| LLM-HR-8 | 用户输入输出数据违规用于训练且无授权 | 隐私泄露风险、违反个人信息保护法 | 隐私政策与实现不一致、无授权记录 |
| LLM-HR-9 | 模型输出高危领域（医疗/金融/政务）幻觉率失控 | 虚假信息造成严重后果 | 高危场景幻觉率测试显著超标且无约束措施 |
| LLM-HR-10 | 大模型系统与承载系统共用特权、越权互访 | 大模型被攻破后横向扩散到核心业务 | 隔离与权限测试发现越权 |

## 三、高风险判定流程

1. 逐条核对通用高风险情形（A 类）与大模型高风险项（B 类）。
2. 命中任一条 → 记录证据（测试结果、截图、配置）→ 判定整体结论"不满足"。
3. 出具《高风险问题整改通知》，明确整改时限与复测要求。
4. 高风险项整改后必须复测，复测通过方可出具最终结论。

## 四、特殊情况说明

- **不适用声明**：大模型系统不面向公众服务（仅内部使用）时，备案、标识、投诉举报等项可调整为"不适用"或"部分适用"，须在报告中书面说明依据，不能简单跳过。
- **一体化部署**：大模型一体机须同时核查硬件接口、预置模型、管理面安全，避免仅测评应用层。
- **多模型并存**：同时使用多个基座模型/API 时，高风险判定针对每个模型实例分别执行。
