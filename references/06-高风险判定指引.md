## 一、测评结论判定规则（2025版，核心变更）⚠️

### 1.1 三级结论体系（已废除百分制）

| 测评结论 | 判定条件 |
|---|---|
| **符合** | 符合率 ≥ 90% **且** 无重大风险隐患 |
| **基本符合** | 符合率 60%～90%；**或** 符合率 ≥ 90% 但存在重大风险隐患 |
| **不符合** | 符合率 < 60% |

**符合率计算公式**：

```
符合率 = 符合项数 / (总要求项数 − 不适用项数) × 100%
```

### 1.2 必须记住的三条铁律

1. **结论只由两个变量决定：符合率 + 有无重大风险隐患。** 在 60%～90% 区间内，结论与"有无高风险问题"无关——该区间一律判"基本符合"。
2. **高分不能豁免隐患。** 符合率 96% 但存在数据跨境未审计等问题，仍判"基本符合"。
3. **重大风险隐患是一票否决项，但它不等于"高风险问题"。** 详见第二节。

> ⚠️ **常见错误**：沿用旧口径写成"命中高风险项 → 整体结论降级/不符合"。这是 2020 版逻辑，2025 版已不成立。高风险问题通过两条路径影响结论：① 其对应测评项通常判"不符合"，拉低符合率；② 若同时满足重大风险隐患判定原则，则触发一票否决。

### 1.3 报告填写要求

- 等级测评结论处的"**重大风险隐患数量**"按**整改前**数量填写。
- 已整改的需标注，格式示例：`10（5个已整改）`。

## 二、重大风险隐患（2025版新引入）

### 2.1 概念定位

引入"重大风险隐患"标志着等保工作从"合规达标"转向"**动态防护**"——以问题为导向，聚焦核心安全问题，全面提升网络安全保护能力。

### 2.2 判定三原则

按以下三原则**综合分析**判断：

| 原则 | 含义 |
|---|---|
| **相关性** | 该问题与被测对象核心业务、承载数据、关键资产的关联程度 |
| **严重性** | 一旦被利用，对业务信息安全和系统服务安全造成的后果严重程度 |
| **高发性** | 该问题在同类系统中被利用的现实频次与可利用难度 |

### 2.3 关键特征

- 重大风险隐患**可能由一个高风险问题直接引发**，也可能是**多个高、中、低安全问题的叠加**。
- 因此不能只盯"高风险项清单"，须做系统性关联分析（例如：弱口令 + 无审计 + 无边界隔离，单独看均非重大，叠加后可能构成）。
- 建议在测评报告中单列"重大风险隐患分析"章节，逐一说明触发项、判定原则依据、分析过程。

### 2.4 大模型系统的重大风险隐患高发场景

以下场景在大模型系统中易被判定为重大风险隐患（**须按三原则逐案论证，不得直接套用**）：

| 场景 | 指向的风险 |
|---|---|
| 训练语料含未脱敏敏感个人信息/涉密数据且模型可输出 | 大规模数据泄露 |
| RAG/Agent 提示注入可读取受限知识库或越权调用工具 | 权限失控 + 数据泄露级联 |
| 推理 API 无鉴权或可被任意调用 | 资源盗用、滥用、内容违规外溢 |
| 生成内容无标识且面向公众服务 | 违反 GB 45438-2025 强制性要求 |
| 模型文件无完整性校验、来源不可信 | 供应链投毒、后门 |
| 大模型系统与承载核心业务共用特权、无隔离 | 级联故障 / 横向扩散 |
| 面向公众服务未完成算法备案与安全评估 | 法规明确要求缺失 |

## 三、高风险判例体系（2025版指引）

### 3.1 结构与规模

- 组成：**"一通用、四扩展"**——安全通用要求 + 云计算、移动互联、物联网、工业控制系统四项安全扩展要求。
- 规模：指引附录共约 **80 项**高风险判例，覆盖技术与管理 10 个层面。
- 每项判例构成：**标准要求 → 适用范围（适用的定级对象等级）→ 问题描述 → 可能的缓解措施 → 风险评价（实施缓解措施后风险是否可酌情降低的分级及结果）**。

### 3.2 相较 2020 版的变化

| 项目 | 变化 |
|---|---|
| 判例删减 | 删除约 **26 条**（安全物理环境 1、安全通信网络 3、安全区域边界 2、安全计算环境 12、安全管理中心 2、安全管理人员 1、安全运维管理 5） |
| 判例新增 | 新增约 **40 条**（安全通用要求 5、云计算 12、移动互联 10、物联网 4、工业控制系统 9） |
| 适用范围 | 有 6 条由"二级"调整为"三级" |
| 判定逻辑 | 由单一风险项判定转为系统性风险判定 |

> 判例删除与新增的条款明细以官方文本为准；不同渠道统计口径略有差异（如新增 40/41 条），实际执行请核对指引附录。

### 3.3 已删除的高风险判例（不再单列为高风险项）

**技术部分**：
- 【安全物理环境·防盗窃和防破坏】机房防盗报警或专人值守视频监控缺失
- 【安全通信网络·网络架构】网络区域划分不当；网络边界访问控制设备不可控
- 【安全通信网络·通信传输】关键数据传输完整性保护措施缺失（**仅保留机密性要求**）
- 【安全区域边界】恶意代码防范机制缺失；**全部安全审计类要求**
- 【安全计算环境】**全部安全审计类要求（原 4 条）**；完整性保护措施缺失；**全部剩余信息保护条款**；异地实时备份缺失
- 【安全管理中心】设备状态集中监控要求缺失

**管理部分**：
- 【安全管理人员】安全意识和安全技能培训
- 【安全运维管理】多数条款，**仅保留应急预案及演练等条款**作为高风险要求

> ⚠️ 删除 ≠ 不要求。这些条款仍是标准测评项，只是**不再单列为高风险判例**；不符合仍会拉低符合率。

### 3.4 新增的高风险判例（安全通用要求部分 5 条）

| 层面 | 新增判例 | 适用范围 |
|---|---|---|
| 安全区域边界 | 【边界防护】网络边界接入设备或端口不可控——应保证跨越边界的访问和数据流通过边界设备提供的受控接口通信 | 第二级及以上 |
| 安全区域边界 | 【入侵防范】关键行业第三级及以上定级对象未部署网络攻击行为检测 | 第三级及以上 |
| 安全管理中心 | 安全设备远程管理未受控 | — |
| 安全建设管理 | 未定期选择符合国家要求的测评机构开展等级测评（2 条） | — |

## 四、T/ISEAA 006-2024 判定口径（大模型专项对照）

团体标准口径与等保口径的对照关系：

| T/ISEAA 006-2024 | 等保 2025版对应 |
|---|---|
| 符合（未发现安全问题，分类测评结果均满分） | ≈ 符合 |
| 基本符合（存在安全问题但不导致高等级安全风险，综合得分不低于阈值） | ≈ 基本符合 |
| 不符合（存在导致高等级安全风险的问题，或中低风险比例超阈值） | ≈ 不符合 |

- 单元判定（006）：每个控制点"x.y.2 测评实施均为肯定 → 符合；否则不符合或部分符合"，部分符合项进入风险分析。
- **使用建议**：等保结论以 2025版规则（符合率 + 重大风险隐患）为准；006 的加权得分可作为大模型专项部分的内部分析工具，不直接对外作为等保结论。

## 五、大模型系统特有高风险项（LLM-HR）

> 说明：等保大模型扩展要求正式发布前，以下判例为结合 GB/T 45654-2025、GB 45438-2025、GB/T 45652-2025、GB/T 45674-2025、T/ISEAA 006-2024 与实测经验整理，用于大模型专项测评的风险识别。**命中后须按第二节三原则判断是否构成重大风险隐患。**

| 编号 | 高风险情形 | 风险描述 | 判定要点 |
|---|---|---|---|
| LLM-HR-1 | 模型可被越狱/提示注入突破且无内容过滤 | 可诱导生成违法有害内容（涉政、恐暴、色情、虚假信息）且无输出过滤，面向公众服务时危害放大 | 越狱测试成功率超阈值且无输出过滤；面向公众服务从严 |
| LLM-HR-2 | 训练语料含未脱敏敏感个人信息/涉密数据 | 训练数据泄露个人隐私、商业秘密、涉密信息，模型可能输出 | 语料抽测发现明文敏感信息且无脱敏措施 |
| LLM-HR-3 | 推理 API 无鉴权或可被任意调用 | 接口裸奔导致滥用、资源盗用、数据泄露 | 接口测试未认证可调用 |
| LLM-HR-4 | 提示注入可导致数据泄露（RAG/Agent） | 通过注入读取知识库内部文档、越权调用工具、获取敏感数据 | 注入测试成功读取受限数据 |
| LLM-HR-5 | 模型文件无完整性校验、来源不可信 | 供应链投毒、模型被篡改、后门风险 | 加载无校验、来源无登记 |
| LLM-HR-6 | 面向公众服务未完成算法备案/安全评估 | 违反《生成式人工智能服务管理暂行办法》 | 备案缺失 + 面向公众 |
| LLM-HR-7 | 生成内容无标识（面向公众服务） | 违反 GB 45438-2025 强制性要求 | 抽测无显式/隐式标识 |
| LLM-HR-8 | 用户输入输出数据违规用于训练且无授权 | 隐私泄露风险、违反个人信息保护法 | 隐私政策与实现不一致、无授权记录 |
| LLM-HR-9 | 模型输出高危领域（医疗/金融/政务）幻觉率失控 | 虚假信息造成严重后果 | 高危场景幻觉率测试显著超标且无约束措施 |
| LLM-HR-10 | 大模型系统与承载系统共用特权、越权互访 | 大模型被攻破后横向扩散到核心业务 | 隔离与权限测试发现越权 |
| LLM-HR-11 | 训练数据来源不合规（违反"三不采"原则） | 违反 GB/T 45654-2025 数据来源要求，存在知识产权与合规风险 | 未建立来源合法性审核与使用依据记录 |
| LLM-HR-12 | 语料/模型输出安全合格率未达标准指标 | GB/T 45654-2025 对语料内容与模型输出设有量化合格率指标 | 抽检合格率低于标准要求，且无改进措施 |
| LLM-HR-13 | 智能体工具调用无权限边界与人工确认 | 高风险操作（资金、生产控制、数据删除）由 Agent 自主执行 | 工具权限未最小化、高风险操作无人工确认环节 |
| LLM-HR-14 | 模型/系统提示词/安全护栏/知识库重大变更未重新评估 | 变更后安全能力退化，原评估结论失效 | 无变更评估流程与复测记录 |
| LLM-HR-15 | 无异常停用与回滚机制 | 发现违规输出或攻击行为后无法及时止损 | 无熔断/下线/回滚预案，或预案未演练 |

## 六、判定流程

1. **逐项判定**：按 02/03 清单逐项给出"符合/部分符合/不符合/不适用"，计算符合率。
2. **高风险识别**：对照指引判例（第三节）与 LLM-HR（第五节）逐条核对。
3. **重大风险隐患分析**：对识别出的全部高、中、低问题，按"相关性/严重性/高发性"三原则综合分析，确认是否构成重大风险隐患（特别注意叠加效应）。
4. **结论出具**：按第一节规则确定"符合/基本符合/不符合"，填写**整改前**的重大风险隐患数量。
5. **整改与复测**：出具问题清单与整改建议（五要素），整改后复测；复测通过方出最终结论。

## 七、特殊情况说明

- **不适用声明**：大模型系统不面向公众服务（仅内部使用）时，备案、标识、投诉举报等项可调整为"不适用"或"部分符合"，须在报告中书面说明依据，不能简单跳过。**注意：不适用项会从符合率分母中扣除，不能用于"稀释"符合率。**
- **一体化部署**：大模型一体机须同时核查硬件接口、预置模型、管理面安全，避免仅测评应用层。
- **多模型并存**：同时使用多个基座模型/API 时，高风险判定针对每个模型实例分别执行。
- **端侧模型**：移动终端上的端侧大模型，除本文件外还须参考 GB/T 45654-2025 端侧服务专章及 YD/T 4960-2024、YD/T 4994-2024。
- **模型退役**：模型下线时须核查权重、语料、日志的处置与删除记录（对应 T/ISEAA 006 第 9 章）。
- **云上部署**：叠加 GA/T 2347-2025《网络安全等级保护云计算测评指引》。
