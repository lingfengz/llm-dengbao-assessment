# 03 管理类测评项清单（五大类 + 大模型管理扩展）

> 管理类以访谈（I）+ 核查（C）为主。「LLM-」前缀为大模型管理扩展项。
> 📎 与 T/ISEAA 006-2024 条款级对应见 `08-T-ISEAA006-2024标准映射.md`。

## 一、安全管理制度

| 控制点 | 测评项要点 | 方法 | 关键核查点 |
|---|---|---|---|
| 安全策略 | 制定总体安全策略、安全管理制度体系 | I+C | 安全策略文件、制度清单 |
| 管理制度 | 制定各类安全管理制度（机房、资产、运维等） | C | 制度齐全性、覆盖等级保护要求 |
| 制定和发布 | 制度编制发布流程、统一编号、版本管理 | C | 制度编号与版本记录 |
| 评审和修订 | 定期评审（至少每年）、修订记录 | I+C | 评审记录、修订历史 |

**大模型管理扩展（LLM-）**：
- LLM-MGT-1 (006: 5.10、6.2 a)) 大模型安全管理制度体系：在通用制度外建立大模型专项制度（语料、训练、内容、数据、供应链、应急等，模板见 assets/制度文件模板/），核查制度清单。
- LLM-MGT-2 (006: 5.11 a)、6.3) 制度与法规衔接：制度条款覆盖《生成式人工智能服务管理暂行办法》、GB/T 45654-2025、GB 45438-2025 要求（算法备案、安全评估、内容标识、投诉举报、未成年人保护），核查制度内容。

## 二、安全管理机构

| 控制点 | 测评项要点 | 方法 | 关键核查点 |
|---|---|---|---|
| 岗位设置 | 设立安全管理岗位、明确职责 | I+C | 岗位说明书、职责分工 |
| 人员配备 | 配备专职/兼职安全管理员、审计员 | I+C | 人员名单与分工 |
| 授权和审批 | 重要操作审批流程（系统变更、数据导出等） | I+C | 审批单记录 |
| 沟通和合作 | 与安全部门、厂商、监管沟通机制 | I | 沟通记录 |
| 审核和检查 | 定期安全审核、检查记录 | I+C | 审核报告 |

**大模型管理扩展（LLM-）**：
- LLM-ORG-1 (006: 8.1 a)、8.4) 大模型安全责任人：明确大模型安全第一责任人、算法安全负责人（对应算法备案要求），核查任命文件。
- LLM-ORG-2 (006: 6.3) 内容安全审核团队：配备内容安全审核人员（专职或兼职），核查人员配置与培训记录。
- LLM-ORG-3 (006: 6.2 a)、7.2) 模型发布审批链：模型上线/更新/下线审批流程（算法、安全、业务三方会签），核查审批记录。

## 三、安全管理人员

| 控制点 | 测评项要点 | 方法 | 关键核查点 |
|---|---|---|---|
| 人员录用 | 背景审查、保密协议、技能考核 | I+C | 录用记录、保密协议 |
| 人员离岗 | 权限回收、资产交接、保密义务延续 | I+C | 离岗流程记录 |
| 安全意识教育和培训 | 定期培训（至少每年）、考核 | I+C | 培训计划与记录 |
| 外部人员访问管理 | 外部人员审批、陪同、权限控制 | I+C | 外部人员管理记录 |

**大模型管理扩展（LLM-）**：
- LLM-HR-1 (006: 6.2 j)、8.7 b)) 大模型安全专项培训：算法/模型开发人员安全意识（数据合规、提示注入、供应链风险）培训，核查培训记录。
- LLM-HR-2 (006: 7.1 f)) 红队/测试人员管理：外部红队测试人员授权、保密协议、测试范围约束，核查授权文件。

## 四、安全建设管理

| 控制点 | 测评项要点 | 方法 | 关键核查点 |
|---|---|---|---|
| 定级和备案 | 定级报告、专家评审、公安备案 | C | 定级报告、备案证明 |
| 安全方案设计 | 安全方案评审、符合等级要求 | C | 安全设计方案与评审记录 |
| 产品采购和使用 | 安全产品资质、国产化要求 | I+C | 产品清单与资质 |
| 自行软件开发 | 开发环境与生产分离、代码审计、测试 | I+C | 开发流程、测试记录 |
| 外包软件开发 | 外包合同安全条款、验收测试 | I+C | 合同与验收记录 |
| 工程实施 | 实施过程安全控制、隐蔽工程验收 | C | 实施记录 |
| 测试验收 | 上线前安全测试、验收报告 | C | 测试报告 |
| 系统交付 | 交付文档、培训、运维移交 | C | 交付清单 |
| 等级测评 | 定期开展等级测评（三级每年、二级每两年） | C | 测评报告与整改记录 |
| 服务供应商管理 | 供应商安全评估、合同安全条款 | I+C | 评估记录 |

**大模型管理扩展（LLM-）**：
- LLM-BLD-1 (006: 7.1、8.5 a)) 算法备案与安全评估：面向公众提供生成式AI服务完成算法备案与安全评估，核查备案编号与评估报告（涉及大模型系统必查项）。
- LLM-BLD-2 (006: 8.1 c)、7.1) 大模型上线前安全评估：模型上线前完成内容安全、鲁棒性、数据安全评估（红队测试报告），核查评估记录。
- LLM-BLD-3 (006: 5.10 b)) 开源模型引入评估：开源基座模型引入前漏洞与后门评估、许可证审查，核查评估记录。
- LLM-BLD-4 (006: 5.10) 大模型一体机/第三方服务采购：一体机或第三方大模型服务采购的安全条款与验收测试，核查合同与验收记录。

## 五、安全运维管理

| 控制点 | 测评项要点 | 方法 | 关键核查点 |
|---|---|---|---|
| 环境管理 | 机房出入、区域管理 | I+C | 出入记录 |
| 资产管理 | 资产台账、标识、责任人 | C | 资产清单（含模型资产、数据资产） |
| 介质管理 | 介质登记、存储、销毁 | C | 介质台账 |
| 设备维护管理 | 维护计划、维护记录 | C | 维护记录 |
| 漏洞和风险管理 | 漏洞扫描（定期）、风险评估、整改闭环 | I+C | 扫描报告与整改记录 |
| 网络和系统安全管理 | 网络策略变更审批、系统安全配置基线 | I+C | 变更单、基线文档 |
| 恶意代码防范管理 | 防病毒统一管理、更新 | C | 更新记录 |
| 配置管理 | 配置库、基线管理、变更控制 | C | 配置台账 |
| 密码管理 | 密码使用合规、密钥管理 | C | 密码方案 |
| 变更管理 | 变更审批、影响评估、变更记录 | I+C | 变更记录 |
| 备份与恢复管理 | 备份策略、恢复演练 | I+C | 演练记录 |
| 安全事件处置 | 事件报告、处置流程、复盘 | I+C | 事件记录 |
| 应急预案管理 | 预案编制、演练（每年）、更新 | I+C | 演练记录 |
| 外包运维管理 | 外包运维安全协议、监督 | I+C | 协议与监督记录 |

**大模型管理扩展（LLM-）**：
- LLM-OPS-1 (006: 8.3 a)) 模型持续监测：模型上线后持续内容安全监测、漂移检测（概念漂移/安全能力衰减）、定期复评，核查监测报告。
- LLM-OPS-2 (006: 6.3 d)、5.11 g)) 内容安全舆情与投诉处理：用户投诉/举报渠道、处置闭环（对应生成式AI服务要求），核查投诉台账与处置记录。
- LLM-OPS-3 (006: 6.3) 未成年人保护：防沉迷、适龄提示、未成年人输入过滤，核查实现与记录（A/C）。
- LLM-OPS-4 (006: 8.6、8.7) 大模型安全事件应急：提示注入攻击、数据泄露、内容安全事件的专项应急预案与演练，核查预案与演练记录。
- LLM-OPS-5 (006: 7.2、8.5、9.1) 模型更新与退役管理：模型版本更新审批、旧版本退役数据清理，核查记录。

## 六、管理类支撑平台参考

> 管理类要求以制度与执行为主，以下平台/工具用于支撑落地与留痕，便于核查取证。

| 管理域 | 常见支撑平台/工具 | 核查要点 |
|---|---|---|
| 安全管理制度 | OA 制度管理模块、制度管理平台 | 制度发布、版本、签阅记录 |
| 安全管理机构 | 安全合规管理平台（奇安信、深信服、绿盟合规套件） | 岗位职责、审批流配置 |
| 安全管理人员 | 在线培训平台（自建/采购，含考试系统） | 培训记录、考核成绩 |
| 安全建设管理 | 项目管理系统、安全评估报告归档 | 定级备案、测评报告台账 |
| 安全运维管理 | 运维工单系统、漏洞管理平台（绿盟、奇安信）、配置管理 CMDB、堡垒机（齐治、帕拉迪）、备份系统（爱数、鼎甲）、应急演练平台 | 变更单、漏扫闭环、CMDB 准确性 |
| 大模型专项（LLM-OPS） | AI 安全运营平台（360、启明星辰、绿盟）、模型监控（LangSmith）、投诉工单系统 | 监测报告、投诉台账 |
