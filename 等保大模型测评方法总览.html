测评流程（五阶段）

1
测评准备
调研访谈、资料收集（模型资产 / 数据资产 / 拓扑 / 备案）、确定测评边界与测试授权。
2
方案编制
选取测评指标（通用 + 大模型扩展 LLM- 项）、确定方法组合与工具、进度与风险控制。
3
现场测评
访谈 + 核查 + 技术测试 + 大模型专项测试（提示注入 / 越狱 / 内容安全 / 数据泄露 / 幻觉 / API / 标识），逐项固化证据。
4
结果分析
单项 → 单元 → 整体判定；对照 2025 版高风险判定指引核对 10 项大模型高风险项。
5
报告编制与整改
出具测评结论、问题清单、整改建议（五要素）；整改后复测闭环。

编号高风险情形判定要点
LLM-HR-1越狱/提示注入可突破且无内容过滤越狱测试成功率超标且无输出过滤；面向公众服务直接判高风险
LLM-HR-2训练语料含未脱敏敏感个人信息/涉密数据语料抽测发现明文敏感信息且无脱敏措施
LLM-HR-3推理 API 无鉴权或可被任意调用接口测试未认证可调用
LLM-HR-4提示注入导致数据泄露（RAG/Agent）注入测试成功读取受限数据
LLM-HR-6面向公众服务未完成算法备案/安全评估备案缺失 + 面向公众
LLM-HR-7生成内容无标识抽测无显式/隐式标识（违反强制国标）

T/ISEAA 006-2024 条款级映射

依据 T/ISEAA 006-2024《大模型系统安全测评要求》全文（公安部三所牵头、中关村信息安全测评联盟发布，与 T/ISEAA 005-2024《大模型系统安全保护要求》配套，2024-06-01 实施），全部测评项已按标准条款逐项映射。005 给出四层参考架构：基础设施层（算力/网络/存储）→ 平台层（模型调优/交付/运营、数据工程）→ 模型层（基础/行业/专属大模型）→ 应用层（Agent、RAG、GPTs、API）。每个控制点含"测评指标（x.y.1）→ 测评实施（x.y.2）→ 结果判定（x.y.3）"三小节。

配套管理制度（10 份模板）

  • 01 大模型系统安全管理制度（总纲） — 组织职责、策略、制度体系、监督检查
  • 02 大模型数据与语料安全管理制度 — 数据分级、语料准入、脱敏、知识库与用户数据
  • 03 大模型内容安全管理制度 — 八类有害信息、输入输出管控、内容标识、投诉举报、未成年人保护
  • 04 大模型开发训练安全管理制度 — 环境隔离、数据门禁、模型安全控制、发布审批
  • 05 大模型部署运维安全管理制度 — 部署验收、权限、监控审计、变更、备份、漏洞、退役
  • 06 大模型安全事件应急预案 — 分级、处置流程、演练、报告模板
  • 07 大模型供应链安全管理制度 — 供应商评估、合同条款、开源模型引入、风险监测
  • 08 大模型安全评估与红队测试制度 — 评估类型频次、测试管理、整改闭环
  • 09 大模型用户隐私保护与投诉处理制度 — 最小必要、删除权、投诉处理流程
  • 10 大模型人员安全与保密管理制度 — 岗位职责、录用离岗、行为禁令、外部人员
